# Privacy Policy — Shhh

**Shhh collects no data. None.**

- No analytics, no ads, no tracking, no accounts.
- All settings (your schedule, volume preferences) are stored only on your device and are removed when you uninstall the app.
- The only network use is the **updater**, and it is under your control: the automatic check is **off by default**, and a check — automatic or manual — sends exactly one anonymous HTTPS request to the GitHub releases API (`api.github.com`) to read the latest version, plus the APK download from GitHub if you choose to update. Nothing about you or your device is sent, and nothing else is ever transmitted.

The permissions Shhh requests (Do Not Disturb access, Alarms & reminders, Notifications, Nearby devices, Internet, Install unknown apps) are used exclusively to switch ringer modes, fire timers, show the optional countdown, detect Bluetooth headphones, and check for/install updates from GitHub. Details: see the README.
